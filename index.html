WH40k 11th

Repo is live. The companion HTML is too large to push through chat, so the first publish is one file drop.

  1. On your computer open the Grok project file WH40k_11th_V12.5.html.
  2. Open github.com/rxguzma/wh40k-11th/upload/main.
  3. Drop that file, rename it to index.html, and commit.
  4. Repo → Settings → Pages → Source GitHub Actions. Approve the github-pages environment if GitHub asks.
  5. Bookmark rxguzma.github.io/wh40k-11th.

After that file is index.html, chat updates and the in-app Update app button take over.
